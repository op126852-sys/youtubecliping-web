# YouTube Clip Studio

Paste a YouTube link, choose how many clips you want and how long each one
should be, and get back downloadable clips — with optional burned-in
subtitles (existing YouTube captions, or auto-generated locally with
[faster-whisper](https://github.com/SYSTRAN/faster-whisper)).

A full-stack app: a Node/Express API that drives `yt-dlp` + `ffmpeg`, and a
React/Tailwind frontend for the paste-link → processing → results flow.

## How it works

1. **Paste a link.** Pick the number of clips (1–10), clip length (5–180s,
   with 15/30/60/90s presets), and a subtitle mode.
2. **It downloads and splits.** The backend fetches the video with `yt-dlp`,
   computes evenly-spaced clip start times across the video's duration, and
   cuts each one with `ffmpeg`.
3. **Subtitles, if requested.** Either burns in the video's existing YouTube
   captions, or transcribes the audio locally with `faster-whisper` — both
   paths correctly re-time the subtitle cues to each clip's own timeline
   (not just the source video's), which is the fiddly part of doing this
   right.
4. **Download your clips.** Each clip gets its own thumbnail, duration, and
   download link.

See [`API_CONTRACT.md`](./API_CONTRACT.md) for the exact REST API and
[`DESIGN_BRIEF.md`](./DESIGN_BRIEF.md) for the UI's palette and style
direction.

## Quickstart

Prerequisites: Node.js 18+, [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) and
`ffmpeg`/`ffprobe` on `PATH`. `faster-whisper` (`pip install faster-whisper`)
is optional, only needed for the auto-generated-subtitles mode.

```bash
# terminal 1 — backend, http://localhost:8787
cd backend
npm install
npm run dev

# terminal 2 — frontend, http://localhost:5173
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` and paste a YouTube link.

## Subtitle modes

| Mode | What it does |
| --- | --- |
| `none` | No subtitle processing. |
| `youtube` | Downloads the video's existing YouTube captions (manual or auto-generated by YouTube) and burns them in. Best-effort: if none exist in the requested language, the job still completes without subtitles. |
| `auto-generate` | Transcribes the audio locally with `faster-whisper` and burns in the result. Requires `faster-whisper` installed on the backend; fails that job with a clear message if it isn't. |

## Status

Built and integration-tested end to end (ffmpeg clip-cutting and subtitle
re-timing verified against a synthetic local video; the HTTP API verified
live). Actually downloading from `youtube.com` requires outbound network
access to YouTube from wherever the backend is deployed.
